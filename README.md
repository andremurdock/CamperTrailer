# Cargo trailer camper build

Andre and Kathleen are turning a 5x10 single-axle cargo trailer into a small camper for multi-week trips. It's a DIY build with a budget of about $6.5k.

![3D model of the camper](images/3d-model.png)

## What's in the camper

- **Bed up front:** a full tri-fold mattress on removable plywood panels set on E-track beams. During the day it turns into a sofa and desk.
- **Bolt-in false wall** at the rear with a door, a window and a duct port for the heater. Unbolt it and the trailer hauls cargo again.
- **Deck:** with the ramp lowered, it becomes a 5x5 ft deck under a rear awning.
- **Roof:** a roof fan, a 12V rooftop AC/heater and a skylight.
- **Power:**
  - 200Ah lithium battery in a box on the tongue.
  - 200W folding solar panel.
  - Champion 2500 generator or campsite power, through an 80A converter/charger.
- **Wash corner:** a sink stand with a small water heater and a cassette toilet underneath.
- **Heat and cooking:** a portable diesel heater on the deck, and outdoor cooking on a propane stove.

## Viewing the 3D model

GitHub's file view shows `index.html` as code. To see the model running:

1. Push this folder to a GitHub repo.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then pick `main` and `/ (root)`, and click **Save**.
4. After about a minute the model is live at `https://<your-username>.github.io/<repo-name>/`.

You can also download `index.html` and open it in any browser. It needs an internet connection to load three.js.

## A note if you copy this build

This is a personal plan, not engineered drawings. Check your own trailer's measurements, weights and brake requirements, and have someone qualified look at the 120V wiring if you're not sure about it.
